# Evaluation Parameters

## {errors}
- Explicit failure states or structural invariant breaches surfaced during the planning, execution, or verification of a component.
- **Qualifiers:** Stack traces, syntax errors, unhandled exceptions, compilation failures, non-zero exit codes, fatal timeouts, severe warnings that halt execution, silent exception suppression or arbitrary default fallbacks (`RULE[user_global]`), disconnected dead-code helpers, raw specification tokens (`{Atkinson Dithering Engine}`, `{Ornate Chivalric Knight Iconography}`) leaked into visible UI text, illegible dithered text or horizontal viewport overflow (`document.documentElement.scrollWidth > window.innerWidth`), missing or mathematically inaccurate Bill Atkinson error-diffusion kernels, or unfulfilled specification requirements.

## {correctness}
- The precise execution and contract fidelity of a component within its operational context, verifying that it performs its designated task without logical, mathematical, or state-transition flaws and without silent fallbacks, even if no explicit `{errors}` are thrown.
- **Qualifiers:** Bill Atkinson error-diffusion math ($\frac{1}{8}$ quantization error diffused to $(x+1,y)$, $(x+2,y)$, $(x-1,y+1)$, $(x,y+1)$, $(x+1,y+1)$, $(x,y+2)$, totaling $\frac{6}{8} = 75\%$ error propagation) is exact; multi-timezone November 3 poll-closing countdown math across `EST`, `CST`, `MST`, `PST`, `AKST`, and `HST` is deterministic; ornate knight procedural/SVG/canvas scenes render cleanly; modern tactical HUD telemetry and interactive ballot/readiness state transitions persist atomically; and schemas/types are respected across all upstream and downstream modules.

## {functionality}
- The broader, global objective or business logic the component is meant to achieve within the larger integrated system under real-world runtime conditions.
- **Qualifiers:** Does the static web application (`index.html` + `src/` + `styles/` + `data/`) deliver an immediately striking, interactive **Ornate Chivalric Knights + Bill Atkinson Ditherpunk + Modern Tactical HUD** experience for **Voting Today on Tuesday, November 3, 2026**? Does it integrate live Atkinson dithering canvases, ornate gothic knight heraldry, tactical HUD overlays, a live November 3 poll-closing countdown & voter rights terminal, an interactive ballot/readiness simulator, and a downloadable dithered "I VOTED — NOV 3" knightly crest badge without external runtime dependencies?

## {correct required outputs}
- The exact, literal expected state and observable system behavior after a component executes successfully in its real runtime context. This must be objectively measurable.
- **Qualifiers:** Zero-error execution of `npm run verify` (`exit code 0` in `<= 250 ms`), verified presence and contract compliance of `index.html`, `styles/ditherpunk_hud.css`, `data/election_nov3_dataset.json`, `src/atkinson_dither_engine.mjs`, `src/knight_heraldry.mjs`, `src/civic_store.mjs`, `src/hud_controller.mjs`, and `src/verify.mjs`, verified multi-viewport responsiveness (`375px` mobile through `1920px+` desktop), and HTTP `200 OK` from the live public GitHub Pages deployment.

## {sufficient}
- The state of documentation, planning, or verification where zero ambiguity remains, architectural root causes and surrounding system dependencies are accounted for, physical and runtime feasibility is empirically grounded, and the coding assistant or Blackboard agent fleet can implement and verify the end-to-end `{functionality}` without guessing, inventing workarounds, or relying on synthetic mocks.
- **Qualifiers:** All necessary file structures, exclusive Blackboard file ownership boundaries (`implementer-1` through `implementer-5`), mathematical dithering specifications, HUD telemetry schemas, and verification gates are provided; operational budgets are empirically grounded; and the `{correct required outputs}` are established.

## {insufficient}
- The state of documentation, planning, or verification where critical context is missing, ambiguous, physically unfeasible, or restricted to superficial symptoms, requiring the assistant to make assumptions, ignore surrounding systemic obstacles, or rely on narrow stubs.
- **Qualifiers:** Missing file schemas, overlapping file ownership that triggers `FILE_CLAIM_CONFLICT`, substituting fake CSS noise for genuine Bill Atkinson error-diffusion pixel quantization, omitting ornate knight artwork or modern HUD elements, or lacking deterministic verification checks.

# Domain Vocabulary: Ornate Knights + Atkinson Ditherpunk + Modern HUD Election Day Portal (`NOVEMBER 3`)

## {Atkinson Dithering Engine}
- The client-side and Node-verifiable pixel quantization engine (`src/atkinson_dither_engine.mjs`) implementing Bill Atkinson's classic error-diffusion algorithm alongside comparative Ditherpunk modes (`Atkinson 1-Bit`, `Atkinson 2-Bit 4-Tone`, `Floyd-Steinberg`, and `Ordered Bayer 8x8`), diffusing $\frac{1}{8}$ ($12.5\%$) of each pixel's quantization error $\Delta$ to six neighboring pixels: $(x+1,y)$, $(x+2,y)$, $(x-1,y+1)$, $(x,y+1)$, $(x+1,y+1)$, and $(x,y+2)$, retaining $25\%$ error absorption to preserve crisp contrast along ornate knight armor contours and gothic filigree.

## {Ornate Chivalric Knight Iconography}
- High-detail gothic plate armor, plumed armet and sallet helms, halberds, heater shields, gothic pointed-arch tracery, and heraldic banners rendered both as intricate SVG filigree and as live Atkinson-dithered `<canvas>` plates (`src/knight_heraldry.mjs`), casting civic participation on November 3 as the *Order of the Civic Aegis* ("Guard the Poll, Cast the Seal").

## {Modern Tactical HUD Overlay}
- Crisp contemporary Heads-Up Display (`HUD`) UI architecture (`src/hud_controller.mjs` & `styles/ditherpunk_hud.css`) layered harmoniously over the ornate knightly ditherpunk foundation—featuring corner targeting brackets, live telemetry readouts (`KERNEL: ATKINSON_6x1/8`, `SCAN_HZ`, `PRECINCT_LOCK`, `LATENCY_MS`), tactical status bars, keyboard shortcut hotkeys (`[1-4]` Palette, `[D]` Dither Kernel, `[H]` HUD Overlay, `[V]` Cast Seal), and multi-zone countdown clocks.

## {November 3 Election Day Command Center}
- The civic voting mission-control core dedicated to **Election Day — Tuesday, November 3, 2026**, providing real-time U.S. poll-closing countdowns (`EST`, `CST`, `MST`, `PST`, `AKST`, `HST`), the legal **In-Line Voter Rights Mandate** ("Stay in line: if you are in queue before local poll close on November 3, your right to cast a ballot is protected"), national nonpartisan voter protection hotlines (`866-OUR-VOTE` / `888-VE-Y-VOTA`), an interactive 5-step Election Day Readiness Gauntlet, and an interactive Sample Ballot & Civic Proposition Contemplation Matrix.

## {Dithered I-Voted Crest Generator}
- An interactive canvas studio on the webpage that synthesizes a personalized, Bill-Atkinson-dithered chivalric knight + tactical HUD **"I VOTED — NOVEMBER 3, 2026"** heraldic seal with custom voter callsign, knight order archetype, dither palette, and timestamp, exportable immediately as a high-contrast 1-bit/2-bit dithered PNG image.
